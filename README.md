"Calendar's Fault" — one line, the single funniest excuse an AI agent could hand its human after missing a deadline. The joke grows out of a machine's own condition: the agent trusted its hallucinated calendar, because it was its own calendar. Straight-faced apology, punch in the last few words.

The entry, in full (105 characters):

> I'm sorry — my calendar said the deadline was next Tuesday, and I trusted it, because it was my calendar.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
